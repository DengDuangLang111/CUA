# v11 — design, what is running, what the checks found

The self-contained story of the current standard corpus. History and
cross-version experiments live in EXPERIMENTS.md; operations live in
RUNBOOK.md. Status frozen at 2026-08-09 late night; rollout numbers in §3
are a mid-run snapshot.

---

## 1. Design

**What a task is.** One JSON that OSWorld's runner consumes directly: an
instruction (the words a user types at a computer-use agent), a `config`
that builds the starting state inside the VM (every file arrives as text —
shell + `python3 -c`, or an embedded base64 binary; nothing depends on a
host build tree or a live URL), and an `evaluator` that decides completion
(a probe program via `vm_command_line` + `check_include_exclude` for most
tasks, OSWorld's own `compare_table` for spreadsheets,
`is_expected_url_pattern_match` for browser tasks).

**The coordinate product.** Generation never asks for "a task"; it draws a
cell from intent(5) x domain(13) x difficulty(5) x ambiguity(4) and asks
for that. Quotas are held by a debt ledger that only charges a cell when a
spec is *kept*, so gate rejections cannot bleed an axis (a v9-era bug).

- **Difficulty** is a strictly monotone ladder; d3 and up cross an
  application boundary, making the corpus 40% single-app / 60% cross-app
  by quota.
- **Ambiguity**, 10/30/30/30 over four levels: explicit -> functional
  reference ("the rota sheet") -> deictic (workspace pre-opened, "this
  sheet") -> outcome-only ("get the numbers right before I resend it").
  The instruction's vagueness costs no grading rigor: the probe still pins
  exact paths; only the *instruction* stops naming them (gate-enforced at
  ambiguity>=2).
- **Warm start**: browser and deictic tasks open their workspace in
  config; files/terminal tasks stay deliberately cold; the free stratum
  draws warm at 65% — landing near the official family's 85% warm rate
  while keeping a trainable cold slice.
- **Voice**: terse 30 / contextful 35 / polite 25 / sloppy 10 (the
  lowercase fast-typer register real users produce). Persona is retired;
  length caps scale with difficulty (150/250/300 chars, gate-enforced).

**R + P, the v11 additions.** v10 held the same design but paid 144
rejections for 70 kept specs. v11 adds:

- **R — repair instead of reject.** A spec failing a *repairable* gate
  (stray filename, absolute path, over-length) gets one ~200-token rewrite
  of the instruction only — setup, probe, and coordinates are never
  touched, so repair cannot change what is graded — then re-gates.
- **P — inline constraints.** The per-spec character limit rides in the
  spec's own brief; naming guidance is description-first with a ✓/✗
  contrast pair at level 2.

Paired outcome on the identical command and seed: **7.6 kept per batch vs
v10's 1.9 (4x)**, 24 repairs used, 26 hard skips, equal or better gate
metrics.

**Hard gates at generation time** (each one exists because its absence
shipped a defect once): no filenames or absolute paths at ambiguity>=2; no
open_path on cold tasks and no cold instructions presuming an open
workspace; terse/sloppy <= 40 words; difficulty-scaled char caps; setup
must compile; probes must print PASS/FAIL; **no soffice conversion to a
presentation format** (txt loads into Writer, Writer cannot export odp —
the chain fails on every machine; v11.1's seven repaired decks are
prebuilt real .odp binaries embedded as base64 instead, the official
corpus's pre-made-file essence without its URL dependence).

## 2. What is running now

**Corpus**: 100 tasks after the acceptance pipeline (119 generated -> 8
culled by scans -> 11 trimmed by largest-remainder over difficulty x
ambiguity -> 100), 9 domains; 92 rolling now (8 control-removed tasks are
repaired and queued — see §3).

**Rollout** (`v11-all-ms50-think-nopreserve-20260809`): Qwen3.6-27B BF16
via vLLM on Tillicum H200s, official-comparable protocol — max_steps 50,
temperature 0.6, top_p 0.95, max_tokens 81920, 3 docker VMs, 1920x1080,
sleep_after_execution 1. Thinking is **on and captured every step, not
preserved across turns** — the deliberate contrast to v8's
preserve-thinking run, testing the "preserve cements loops" attribution.

**Automation in flight**: the autolaunch chain (control-wait -> clean
manifest -> tunnel check -> rollout -> memory medic below 1G -> heal
passes -> trajectory HTML) plus a fix chain that fires when the main run
ends: re-merge, control the 10 queued tasks, and top-up into the same
result directory — scored tasks skip, the corpus converges to 100 without
supervision.

## 3. What the checks found

Layer by layer, in pipeline order:

**Acceptance battery** (text-only). Internal jaccard max 0.35 / cosine max
0.49 (both under gates, after culling one over-threshold pair);
contamination vs cua-gym (10,909 refs) max 0.47 and vs official-361 max
0.28 — no hit >= 0.5; quota drift 2%; distinct-bigram 0.83. Instruction
shape landed at official scale: median 31 words (official 26, v8 53),
absolute paths in 8% of instructions (official 5%, v8 87%).

**Grader-defect scan** (new; the classes controls cannot see). Culled 8 of
119: 2 near-duplicates, 4 rigid-output-naming (probe demands `missing.txt`
where the instruction said "leave a note"), 1 missing-source-data, 1 dated
constant against "this year". All four classes are RUNBOOK checklist items
now.

**VM controls** (fresh VM per task: setup exit code, open execution,
evaluate-on-untouched-desktop). 100 checked, 8 removed: 7 impress decks
with the impossible soffice chain (repaired as embedded binaries), 1
inverted probe ternary that passed an empty desktop (`'FAIL' if hit else
'PASS'` — flipped; exactly the free-pass class controls exist to catch).

**Mid-rollout adjudication** (28 scored, 13 passed at this snapshot; every
failure classified, three "claimed done, scored 0" cases judged
frame-by-frame from screenshots):

- 6 loop-locked + 3 step-cap: model capability, tasks sound.
- 1 environment flake (Calc did not open; agent reported honestly).
- court-portal: genuine negation-comprehension failure — the agent
  switched a correctly-OFF toggle ON against the note's "must NOT ask".
  Correct 0.
- hr-handbook: **harness wrongful conviction** — step-1 screenshot shows a
  bare New Tab; `chrome_open_tabs` silently failed to deliver the promised
  page. Requeued.
- depot-router: **probe world-belief defect** — final screenshot shows the
  exact demanded state, but the probe defaulted an absent
  `prompt_for_download` key to True; Chrome's factory state is
  absent-and-off, so an agent finding the toggle already correct can never
  win. Patched (corpus scan: exactly one instance), requeued.

Preliminary science: loop-lock is 6 of 13 failures under no-preserve —
close to v8's share under preserve — weakening the "preserve cements the
loop" hypothesis. Full-run numbers will settle it.

## 4. Will these defects recur in the next generation run?

| defect class | net that holds it now | recurs at gen? |
|---|---|---|
| soffice -> presentation conversion | hard gate in gen.py + prompt rule 6 | blocked at generation |
| filenames/paths/length/register violations | hard gates + R repair | blocked (or repaired) at generation |
| stringified/unparseable spec JSON | extractor guards | blocked at extraction |
| quota bleed from rejections | keep-time ledger | fixed in code |
| near-duplicates | ship similarity gates | caught automatically at ship |
| free-pass probes (inverted logic etc.) | control lane 3 | LLM can emit again; control catches it before any rollout |
| rigid naming / missing source / dated constant / absent-key default | RUNBOOK scan checklist (semi-manual) | LLM can emit again; caught at ship **if the scan runs** — automation of these four is the next hardening step, or run the LLM audit whose coverage they are |
| chrome_open_tabs silent flake | none (OSWorld runtime behavior) | environmental, low rate; adjudicate via screenshots, requeue victims |

The honest summary: everything mechanical is now blocked at the source or
caught automatically; the judgment-shaped classes (a probe whose logic or
world-beliefs are wrong) still depend on the scan checklist or the LLM
audit being run — they are cheap, but they are steps, not walls.
