## 2 一共用到三份语料

三份语料同源:教师 **Qwen3.8-27B** 在 ostg 生成的任务上跑出的轨迹,
经 checker 判定 + 筛选而来。学生模型一律 **Qwen3.5-4B**。

```
教师 rollout
  ├── run v11-100-t1-20260814  (100 题池)
  └── run v11-500-t1ms50-20260814 (500 题池)
            │
            ├─→ ① q38-v11100    只取 100 池
            ├─→ ② B             两池合并
            └─→ ③ Bs            = B,再屏蔽超长 think 目标
```

| # | 语料 | 轨迹 | 样本 | 来源 run | 处理方式 |
|---|---|---|---|---|---|
| ① | **q38-v11100** | 69 | 1,196 | 仅 v11-100 | 基础流程:checker 判 1.0 才收,步级过滤幻觉动作,末步不做处理 |
| ② | **B** | 312 | 5,659 | v11-100(1,181)+ v11-500(4,478) | 同上,语料规模扩到 4.7 倍 |
| ③ | **Bs** | 312 | 5,586 | v11-100(1,167)+ v11-500(4,419) | **= B**,唯一改动:把 think 超过 2048 token 的 **73 个目标**屏蔽掉 |

### 2.1 ② 和 ③ 的处理差别(唯一差别)

- **轨迹集合完全相同**(都是那 312 条),差的只有 **73 个样本**
- 屏蔽的是**训练目标**:那 73 步的 `<think>` 不再计算 loss
- **这些步仍然留在历史里** —— 模型在后续步骤中照样看得到它们
- 影响量级:占全部目标 token 的 **15.6%**(集中在极少数超长推理上)

### 2.2 ① 和 ②/③ 的处理差别

处理流程相同,**差别只在覆盖范围**:① 只用 100 题池(69 轨迹),
②③ 合并了 500 题池(312 轨迹)。域分布也随之改变。

| 语料 | 用它的臂 | 臂之间差什么 |
|---|---|---|
| **无(未微调)** | stock 4B | — |

## 5 单变量归因

### 5.1 同语料内(纯训练/服务变量)

| 语料 | 变量 | 对照 | 差值 |
|---|---|---|---|
| ③ Bs | **全量 → LoRA** | 45.81% → 50.86%(未完) | **+5.05** |
| ② B | **1 epoch → 3 epoch** | 31.81% → 41.81% | **+10.00** |
| ② B | **gb64 → gb128** | 41.81% → 43.81% | +2.00 |
| ① v11100 | **preserve_thinking 假 → 真** | 23.81% → 28.00% | **+4.19** |
| ① v11100 | **keepthink → stock 模板**(同权重) | 28.00% → 30.00% | +2.00 |
| ① v11100 | **ep1 → ep3** | 27.81% → 28.00% | +0.19 |

### 5.2 跨语料(数据变量)

| 变量 | 对照 | 差值 |
|---|---|---|
| **B → Bs**(屏蔽 73 个超长 think 目标) | 41.81% → 45.81% | **+4.00** |
| **① → ③**(69→312 轨迹,同时换了优化配方) | 28.00% → 45.81% | +17.81(**非单变量**) |

`B → Bs` 是全表最干净的数据变量:形状、lr、优化器、epoch 全同,
**只差 73 个目标**,值 4 个点。

### 5.3 SFT 相对基座

- **超过基座**:Bs-LoRA(未完)、Bs-gb64、B-gb128 ep2、B-gb64o
- **低于基座**:B-1ep、rich 三变体、lean

最差的 lean 比基座低 **16 个点**。**配方或数据不对,SFT 会把模型弄坏。**
