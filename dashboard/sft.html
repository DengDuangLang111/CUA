What happened, in five steps

  1. The exam raised two red flags. After the first two pilot arms (full-FT and LoRA, 1 epoch on 56 trajectories), the action exam reported think_len_ratio = 0.0 on every trained model — apparent reasoning collapse — and coordinate error flat-or-worse vs the zero-shot baseline.
  2. Training was proven healthy. The trainer's label dump shows loss on the full final turn — reasoning included, opening tag first supervised token, no image-token leakage. The "collapse" could not have come from the loss.
  3. The real defect: a hidden trainer default. ms-swift silently strips <think> from history turns while encoding. But the teacher generated every action seeing its full past reasoning (the Qwen template keeps it for tool-use conversations), and the exam and future deployment render it too. Training was the only link in the chain that deleted it.
  4. The "collapse" was the ruler, not the model. A raw-generation probe showed trained models reasoning fully — the exam's regex just required an opening tag the chat template had already placed in the prompt. The baseline's "healthy" score was its own artifact: it fails to end its turn and hallucinates fake extra rounds, which the regex credited. Exam parser fixed; raw text now logged.
  5. One-flag fix, immediately measurable. Retraining with --preserve_thinking true: step-1 loss halves (context now carries the teacher's plan), eval loss on unseen tasks drops 44% and keeps falling where v1 plateaued. Full run + re-exam land today.

Tier 3 — the arbiter: the student drives the VM itself

9 held-out tasks the teacher passes 9/9, run end-to-end in real VMs, scored by the task's own checker. First result for the v2 model, and the failure mode is one specific pathology rather than diffuse incompetence.

1/9 vs the teacher's 9/9 — and 7 of the 8 failures are the same defect: the model copies its own previous response instead of reading the current screenshot. Receipt: on chrome-downloads the responses at steps 1, 2, 3 and 25 are byte-identical (same reasoning text, same coordinate) while the screenshots demonstrably change. Mechanism: the teacher's step 2 there is wait (let the app load); the student clicks again, an unchanged screen yields an identical response, two identical turns enter the history, and in-context pattern lock does the rest. This is the same defect the action exam registered as "phase lag" — and the exam-time reading that it would self-correct in closed loop was wrong. Single-step exams cannot see compounding; only this tier can.

It is not taught by repeated-action training data: of 873 samples with a previous assistant turn, only 15 (1.7%) have a target identical to the previous step — the loop filters worked. Nor is it an off-by-one: the runner writes each screenshot after env.step(), so a sample's last image is exactly the screen its target action acts on. Live hypotheses, each testable: too little data (916 samples, 1 epoch — a 3-epoch run is training now), preserve_thinking making the copy source richer (testable against the retained v1 checkpoint), and stock-model behavior (a base-model control on this same panel is running).

How the exam scores

metricdefinition
protocolteacher-forced single step: the model gets the exact context the teacher saw, greedy-decodes one response; both sides parsed identically (first action, first coordinate, reasoning before first </think>)
type accstudent's action name equals the teacher's (click vs type vs scroll …)
coord MAEmean |dx|+|dy| in the model-native 0–999 grid, only where both sides gave coordinates and types match — type errors never pollute it. 100 units ≈ 10% of screen span
think ratiomedian student÷teacher first-round reasoning length — the collapse detector

Reading rules: MAE measures agreement with the teacher, not correctness (an open step solved differently scores a large distance; true difficulty is tier-3 rollout success). Panels are not mutually comparable — the baseline's 123-vs-372 gap is panel composition (element geometry, step openness, domain mix), so models are compared within a panel only. Measured run-to-run noise floor: ±9 MAE units (380.3 vs 371.6, same model same panel twice) — differences under ~10 are noise; with n=26/40, treat a few tens as tentative.
