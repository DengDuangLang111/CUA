Pipeline arc

Four corpus generations in one week

v8

206 self-contained tasks, 3 grading routes (probe / table / URL). Found the instruction problem: median 53 words, 87% absolute paths — a colleague's memo, not a user's prompt. 24% pass at step-100 preserve-thinking.

v9

Ambiguity axis + voice registers (4 levels, 10/30/30/30). Superseded before VM time — instructions were still long, and official corpora turned out to pre-open the workspace 85% of the time.

v10

Genre pivot: instructions are prompts typed at an agent + warm-start axis + d3-up crosses apps (60% multi-app). Economics broke: 144 rejections for 70 keeps. Retired to control group.

v11

Repair-instead-of-reject + inline constraints. Same seed and command as v10: 7.6 keeps/batch vs 1.9 (4×), 24 repairs, 26 hard skips. 119 generated → 100 shipped. This is the standard.

Verification funnel

Every layer caught something the others could not

Layer 1 · text gates119 → 117

Similarity + contamination: culled 2 near-duplicate pairs (worst cosine 0.55, one also 0.58 against CUA-Gym).

Layer 2 · grader-defect scan117 → 111 → trim 100

Instruction/setup/probe coherence: 4 rigid output names (probe demands missing.txt, instruction said "leave a note"), 1 missing source data, 1 hard-coded year vs "this year". Then a quota-shaped trim of 11.

Layer 3 · VM controls100 → 92 + 8 repaired

Fresh VM per task: 7 impress decks whose setup used a conversion path that exists on no machine (txt→odp; rebuilt as embedded real .odp binaries, official-style), 1 inverted probe that passed an empty desktop (SFT poison).

Layer 4 · rollout adjudication13 fails, all classified

Frame-by-frame on every "claimed done, scored 0": 1 real agent error (negation flip), 1 harness wrongful conviction (promised page never opened), 1 probe world-belief bug (absent Chrome pref key ≠ True). Last two patched & requeued.

Recurrence guards: mechanical classes are now hard-gated at generation (soffice→presentation ban, filename/path/length gates, extractor guards). Judgment-shaped classes (probe logic, world beliefs) are a documented 4-class scan before every ship, with LLM audit as the deeper option.

Findings

What the experiments established

  1. Instruction length predicts failure on both corpora. Official: 58% pass at ≤15 words → 16% over 60. v8: 33% → 11%. At matched lengths the corpora pass equally — the v8-official gap was length mix, not grading strictness.
  2. The official family pre-opens the workspace (85% of OSWorld-Verified, 82% of OSWorld-V2, 47/47 impress tasks). Self-contained cold starts test a "first mile" official never tests — and it was breaking our runs.
  3. Thinking was silently off in all earlier runs: the agent flag was a DashScope-only no-op and vLLM 0.25 renamed the response field. Fixed; 99.7% of calls now carry captured reasoning.
  4. Repair beats reject. One ~200-token instruction rewrite per fixable gate failure quadrupled per-batch yield at equal gate metrics, with zero drift in setup/probe semantics (spot-checked).
  5. Presentation files cannot be synthesized in the VM (txt→odp exists on no machine; the prompt's own examples taught the pattern one format too far). Decks now ship as prebuilt real binaries, base64-embedded — official's essence without its URL dependence.
  6. Task-model choice held up: Opus 5 corpora carry ~1.5× fewer coverage gaps per task than Opus 4.6 under a fixed third-party judge.
